## About me

I approach software development as a formal **engineering discipline**, not just coding. My core strength lies in **abstracting, modeling, and designing complex systems** before writing the first line of code — applying **Clean Architecture**, **SOLID principles**, **Domain-Driven Design (DDD)**, and **Event-Driven Architecture (EDA)** to build decoupled, maintainable solutions.

I work across the entire technical spectrum: from understanding low-level memory behavior and building native/hybrid **desktop applications** (**WPF**, **Electron**, **Tauri**), to developing modern **full-stack web platforms** (**C# / .NET**, **Go**, **Spring Boot**, **Node.js**, **React**, **Next.js**) and orchestrating **distributed microservices**.

Beyond application logic, I care deeply about how software runs in production and how users interact with it. I integrate **DevOps practices, containerization, and full-stack observability** (**Docker**, **Kubernetes**, **Grafana LGTM stack**) alongside **security threat modeling** and **usability heuristics** — collaborating effectively within **Agile/Scrum** teams to deliver reliable software on time.

## How I work

- 🧱 **Systems Design & Clean Architecture:** Translating complex business domains into formal requirements and **UML** models — structuring codebases around **SOLID principles**, **Clean Architecture**, **Domain-Driven Design (DDD)**, and asynchronous **Event-Driven** workflows (`RabbitMQ`).
- 🚀 **DevOps & Production Observability:** Designing containerized environments (`Docker`, `Kubernetes`, `NGINX`), automating CI/CD pipelines (`GitHub Actions`, `Jenkins`), and instrumenting services with metrics, logs, and distributed traces (`Prometheus`, `Loki`, `Tempo`, `Grafana`).
- 🧪 **Testing on Both Sides:** Writing automated unit and integration tests across ecosystems — `xUnit` for .NET, `Vitest` for TypeScript/React, and `JUnit` for Java.
- 🔍 **Static Analysis & Security by Design:** Keeping code quality, memory safety, and security in check with **SonarQube** and proactive threat modeling (`OWASP Threat Dragon`).
- 🎨 **Usability & Human-Centered Engineering:** Applying **Nielsen's 10 usability heuristics** to align backend behavior with frontend UX (such as transparent system status feedback during server cold-starts).
- 📋 **Agile Collaboration:** Working in iterative **Scrum** sprints and Kanban workflows — prioritizing clear technical communication, time management, and reliable delivery within cross-functional teams.
